[Spec-Kit](https://github.com/github/spec-kit) is GitHub's spec-driven development tool: like [OpenSpec](/tools/openspec) it produces a proposal, a spec, a task list and scenarios for an agent to implement against, supporting our [Spec Driven Development](/methods-and-patterns/spec-driven-development) way of working. Some colleagues have already experimented with it, and it looks like a fine alternative.

We use one spec-driven framework per project, so the folder structure stays consistent across projects — don't mix Spec-Kit and OpenSpec within one project.
