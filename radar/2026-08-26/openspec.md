[OpenSpec](https://github.com/Fission-AI/OpenSpec) is a spec-driven development tool: it generates a proposal, a spec, a task list and scenarios for a change, which an agent then implements against. We use it in our projects to practice [Spec Driven Development](/methods-and-patterns/spec-driven-development).

We use one spec-driven framework per project, so the folder structure stays consistent across projects. [Spec-Kit](/tools/spec-kit) is a fine alternative — pick one per project, don't mix them.
