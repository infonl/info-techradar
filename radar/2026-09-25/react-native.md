[React Native](https://reactnative.dev/) is a popular open-source framework that allows developers to create mobile applications for both iOS and Android using JavaScript and React. Its central principle is "learn once, write anywhere," enabling a single codebase for both iOS and Android applications.

We use it together with [Expo](https://expo.dev/), the open-source toolchain built around React Native, and its EAS (Expo Application Services) cloud services:

- **Code Reuse & Cost-Effectiveness**: React Native allows for maintaining a single codebase for both iOS and Android platforms, and shares language, libraries and skills with our [TypeScript stack](/languages-and-frameworks/typescript) for the web.

- **Managed toolchain**: Expo handles native project setup and SDK upgrades, and provides a rich set of prebuilt modules, which reduces setup and maintenance overhead.

- **EAS Build and Submit**: builds and store submissions run in the cloud, without every developer needing a full native toolchain.

- **EAS Update**: over-the-air updates ship bug fixes and JavaScript changes directly to users' devices without waiting for app store review. It replaces Microsoft CodePush, which was retired together with App Center in 2025.

As with any technology, successful adoption will depend on the specific project requirements and the team's expertise.
