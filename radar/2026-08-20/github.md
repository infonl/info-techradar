We prefer GitHub as source code management and CI/CD solution. We prefer to use GitHub Actions for (CI/CD) software workflow automation.

In line with our preference for a [European Sovereign Cloud](/platforms-and-operations/european-sovereign-cloud), we
are also assessing alternative, European, non-big-tech solutions, such as [Forgejo](https://forgejo.org/),
[Codeberg](https://codeberg.org/) and [code.overheid.nl](https://code.overheid.nl/), the Dutch government's open
source code collaboration platform.
